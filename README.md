# ChisHub

**Community Hub for Information & Stories**

A local community platform for power and internet outage updates, local news, announcements, emergency alerts, and community discussions. Built with Next.js App Router, React JavaScript, Tailwind CSS, and shadcn-style Radix components.

## Run locally

```bash
cd web
npm install
npm run dev
```

Open `http://localhost:3000`.

The complete Next.js frontend lives in the [`web`](./web) directory.

## Routes

- `/` — landing page
- `/login` — resident login
- `/register` — guided account creation
- `/dashboard` — community overview
- `/updates` — community feed
- `/alerts` — alerts and outage reports
- `/map` — location-aware community map
- `/threads` — discussions
- `/marketplace` — local marketplace and services
- `/chat` — neighborhood messaging
- `/notifications` — notification center
- `/profile` — resident profile
- `/settings` — account and app preferences
- `/admin` — moderation console
